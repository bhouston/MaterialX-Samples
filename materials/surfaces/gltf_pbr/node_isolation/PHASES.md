# Node Isolation Phases

This manifest maps all 118 supported non-surface node categories into batches of 10 materials (final phase has 8).

Excluded categories: `gltf_pbr`, `open_pbr_surface`, `standard_surface`, `surfacematerial`.

- `subtract`
- `multiply`
